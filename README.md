# Аниме-дл — бесконечный режим

Фанатские игры по мотивам [narutodle.net](https://narutodle.net) и [dotadle.net](https://dotadle.net) без ограничения «раз в день»: Наруто, Dota 2, Атака титанов и Блич. Переключатель игры вверху страницы.

- **Классика** — угадай персонажа/героя; клетки подсвечиваются зелёным / жёлтым / красным, стрелки показывают «позже/раньше» или «больше/меньше».
- **Картинка / Экран загрузки** — угадай по сильно увеличенному фрагменту арта; каждая ошибка немного отдаляет картинку.

## Запуск

```bash
npm install
npm run dev
```

## Данные

`npm run data` пересобирает все игры (`npm run data:naruto`, `data:dota`, `data:aot`, `data:bleach` — по отдельности).

**Наруто** (`scripts/build-data.mjs`, переводы в `scripts/ru.mjs`)
- персонажи — [Dattebayo API](https://dattebayo-api.onrender.com), только канон манги до главы 699;
- картинки и русские имена — Naruto Wiki (Fandom); имён без русской статьи транслитерируются;
- загадываются топ-150 по длине статьи на вики.

**Dota 2** (`scripts/build-dota.mjs`, ручные данные в `scripts/dota-heroes.mjs`)
- атрибут и сложность — datafeed Valve, роли и тип атаки — OpenDota, год выхода и лор-арт — Dota 2 Wiki (Fandom);
- пол, раса и русские прозвища для поиска — вручную.

**Атака титанов** (`scripts/build-aot.mjs`)
- всё из Attack on Titan Wiki (Fandom): вид, принадлежность, род занятий, сила титана, статус, арка дебюта; цветные картинки из аниме-страниц персонажей;
- загадываются ~70 известных персонажей (список `ANSWER_POOL` в скрипте).

**Блич** (`scripts/build-bleach.mjs`)
- всё из Bleach Wiki (Fandom): раса, принадлежность, должность, отряд, силы (шикай/банкай/…), арка дебюта;
- загадываются топ-130 по «избранному» на MyAnimeList (через Jikan, кэш в `.cache/mal-269.json`).

Общие хелперы для вики и картинок — `scripts/lib.mjs`.

Миниатюры собираются в один атлас (`thumbs.webp`), чтобы грузились одним запросом. Кэш запросов — в `.cache/` (не в git).

## Деплой
